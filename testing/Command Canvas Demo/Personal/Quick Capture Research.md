# Quick Capture Research

## The problem

Useful thoughts arrive while someone is in another app. Opening a full library, choosing a folder, and naming a note can be too much friction.

## Proposed flow

1. Press the global quick-capture shortcut.
2. A small native window appears on the current desktop.
3. Type immediately; press Escape to close or Command/Control+Enter to save.
4. Append the capture to today's inbox note, with a timestamp.
5. During review, split captures into durable notes when useful.

## Acceptance criteria

- [ ] Opens above the active desktop
- [ ] Does not steal the user from their current task after saving
- [ ] Works with the configured macOS and Windows shortcut
- [ ] Keeps every capture as plain Markdown

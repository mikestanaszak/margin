# Margin 0.5.0 Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the automated suite deterministic, align repository tooling and documentation, narrow the registered native command surface, and report partial library-index failures.

**Architecture:** Keep the existing runtime behavior while separating the heavyweight Mermaid integration run from parallel unit tests. Extend the Rust-owned library snapshot with structured warnings and keep indexing usable when individual paths fail.

**Tech Stack:** pnpm 10.15.1, Node 24, Vitest 2, React 18, Tauri 2, Rust, notify, walkdir.

## Global Constraints

- Preserve ordinary UTF-8 `.md` and `.markdown` notes with optional YAML front matter.
- Do not add a database, account, telemetry, or network dependency.
- Do not stage or commit the unrelated untracked `ENGINEERING_REVIEW.md`.
- Use Windows Command Prompt for repository commands.
- Use test-driven development for every behavior change and commit each task independently.

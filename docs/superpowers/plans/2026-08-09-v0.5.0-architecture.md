# Margin 0.5.0 Architecture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the main and capture applications, typed native boundary, oversized frontend controller, native backend, and global stylesheet into focused modules without changing the note format or primary workflows.

**Architecture:** Introduce shared DTO/service modules first, then move feature code behind explicit interfaces. Give Quick Capture its own build entry so the capture webview does not load the editor and preview stack.

**Tech Stack:** React 18, TypeScript, Vite multi-page build, CodeMirror 6, Tauri 2, Rust.

## Global Constraints

- Preserve user-visible behavior except for fixes explicitly specified by the 0.5.0 design.
- Keep React state local; do not add a state-management dependency.
- Keep native filesystem authority in Rust and expose typed service functions to React.
- Keep the main and capture entry bundles independently loadable.
- Do not stage or commit `ENGINEERING_REVIEW.md`.

**Files:**

- Create: `src-tauri/src/windows.rs`
- Create: `src-tauri/src/test_support.rs`
- Modify: `src-tauri/src/lib.rs`

**Interfaces:**
- `model` owns serialized DTOs.
- `paths` owns canonical containment and portable filename helpers.
- `library` owns `LibraryIndex`, snapshot/search/backlink commands, and warnings.
- `notes` owns note CRUD, save conflicts, Trash, and link repair.
- `assets` owns image commands and companion lifecycle.
- `capture` owns Daily append/import commands.
- `windows` owns external-file queueing, shortcut, window, and tray lifecycle.

- [ ] **Step 1: Record the native baseline**

Run: `cargo test --manifest-path src-tauri/Cargo.toml`

Expected: all existing native tests pass.

- [ ] **Step 2: Move shared DTOs and path helpers**

Use `pub(crate)` for cross-module interfaces and keep command functions `pub(crate)` so `lib.rs` can register them. Run `cargo check` after this move.

- [ ] **Step 3: Move library, note, asset, capture, and window groups one at a time**

After each group, run its matching test name filter and `cargo check`. Do not change behavior during mechanical moves. Move tests beside their owning module and use `test_support` only for temporary directories and fixture-copy helpers.

- [ ] **Step 4: Reduce lib.rs to assembly**

`lib.rs` should declare modules, build plugins, manage shared state, register commands, and delegate setup/window events. It must not contain note parsing, search scoring, link rewriting, or image filesystem implementation.

- [ ] **Step 5: Run full native validation**

Run: `cargo fmt --manifest-path src-tauri/Cargo.toml --all`

Run: `cargo test --manifest-path src-tauri/Cargo.toml && cargo check --manifest-path src-tauri/Cargo.toml && cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets --all-features -- -D warnings`

Expected: all commands succeed.

# Margin 0.5.0 Cohesion and Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make discovery, links, tags, capture, view continuity, and background lifecycle consistent, then publish the verified 0.5.0 release.

**Architecture:** Search and backlinks query the same Rust-owned index and link graph. Existing metadata is surfaced without adding editing UI. Native tray lifecycle coordinates with the frontend note session before quitting.

**Tech Stack:** React 18, TypeScript, Tauri 2, Rust, GitHub Actions, Tauri updater.

## Global Constraints

- Defer AI, Git history, importers, graph views, sync, unresolved-link creation, tag editing, and tag filtering.
- Keep note bodies inside the native search index.
- Treat external URLs, anchors, absolute paths, ambiguous targets, and unresolved targets as non-backlink targets.
- Publish only after PR checks and release-artifact verification pass.
- Update `CHANGELOG.md` before creating `v0.5.0`.
